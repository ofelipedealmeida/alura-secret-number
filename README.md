# Git and GitHub Training – Alura

Repository created during the **Git and GitHub training** at [Alura](https://cursos.alura.com.br/course/git-github-compartilhando-colaborando-projetos/).

## 📚 About the Project

This repository is part of my learning journey, where I practice version control concepts and learn how to manage projects using Git and GitHub.

## 🎯 Topics Covered

- Git installation and configuration
- Creating and managing repositories
- Tracking changes and staging files
- Creating, editing, and reverting commits
- Working with branches
- Connecting local repositories to GitHub
- Pushing and pulling changes
- Managing commit history

## 🛠️ Tools

- **Git** – Version control system
- **GitHub** – Remote repository hosting
- **Visual Studio Code** – Code editor and integrated terminal

## 🚀 Purpose

The goal of this repository is to reinforce the concepts learned throughout the training through practical exercises and experimentation.
